# Muhammad Qasim — Portfolio

Personal portfolio: full-stack and Flutter mobile engineer.

**Stack:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 3 · `motion` 12

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
```

To verify a production build while `npm run dev` is running (they would otherwise share `.next`):

```bash
NEXT_DIST_DIR=.next-verify npm run build && NEXT_DIST_DIR=.next-verify npm start
```

## Configuration

|---|---|
| `NEXT_PUBLIC_SITE_URL` | Canonical site URL used for metadata (`metadataBase`). Defaults to `http://localhost:3000`. |

The contact form posts to a Formspree endpoint defined in `src/app/components/Contact.tsx`.
Submissions are delivered to the email address configured in that Formspree form.

## Design system

`src/app/globals.css` is the single source of truth for design tokens (palette, shadows, hairline,
page margin, section rhythm). `tailwind.config.js` reads them via `var()` — never add a literal colour
to a component. Shared primitives live in `src/app/components/ui/`.

Fonts are self-hosted from `src/fonts/` (latin subset, variable; SIL OFL):
Bodoni Moda (display), Hanken Grotesk (body), JetBrains Mono (technical).

```bash
npm run lint     # next lint (ESLint, next/core-web-vitals + next/typescript)
```

CI (`.github/workflows/ci.yml`) runs lint and build on every push and pull request.

## Hero portrait

`public/images/hero-portrait.png` is the source cutout. The site serves `hero-portrait.avif` / `.webp`,
generated by `node scripts/export-portrait.mjs` (re-run it whenever the PNG changes).

## Theming

Light is the default token set on `:root`; dark follows the system preference unless the user
chose a theme with the nav toggle (stored in `localStorage`, applied before first paint).
Tokens: `src/app/globals.css`.

## Content

Content is currently hardcoded in the components under `src/app/components/`.
Static assets live in `public/` (project screenshots in `public/images/projects/`, resume at `public/resume.pdf`).
